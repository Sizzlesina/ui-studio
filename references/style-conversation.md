# Helping the user choose a visual direction

Ask about style after establishing the project. Offer a few relevant options rather than reciting every style. Always allow the user to name a different style or delegate the choice.

| Direction | Plain explanation | Appropriate use and tradeoff |
| --- | --- | --- |
| Minimalism / مینیمالیسم | Restrained palette, clear hierarchy, fewer competing elements, deliberate whitespace | Good for focus; does not mean omitting useful content or hiding necessary actions |
| Maximalism / ماکسیمالیسم | Expressive color, layered imagery, bold type, rich composition | Useful for energetic cultural or creative brands; requires strong hierarchy to avoid overload |
| Glassmorphism / گلسمورفیسم | Translucent surfaces, blur, layered depth, highlights | Useful for selected overlays or atmospheric interfaces; text contrast and solid fallbacks matter |
| Editorial / ادیتوریال | Typography and content rhythm inspired by well-designed publications | Useful for stories and portfolios; preserve clear navigation and comfortable mobile reading |
| Neo-brutalism / نئوبروتالیسم | Strong borders, bold color, direct typography, visibly structured elements | Can suit outspoken brands; visual force should not make everyday tasks tiring |
| Refined luxury / لوکس و ظریف | Careful proportions, strong imagery, restrained detail, high-quality typography | Quality comes from coherence and content, not a mandatory gold/black or beige palette |
| Playful / بازیگوش | Expressive shapes, approachable illustrations, lively feedback | Fits some consumer and learning products; avoid undermining clarity or credibility |
| Restrained product UI / رابط محصول ساده و دقیق | Predictable components, clear status, appropriate density, efficient tasks | Useful for repeated workflows; still needs a specific identity and thoughtful hierarchy |

Do not present this table as evidence of current trends. Verify trend claims separately when researching the actual project.

## Explain and compare

For a question about a style, explain its appearance, emotional tone, fit for this project, and one practical downside. Keep the explanation short until the user asks for more.

For example:

> گلسمورفیسم از پنل‌های نیمه‌شفاف و محوشدن پس‌زمینه استفاده می‌کند تا حس عمق بدهد. برای بعضی بخش‌های این پروژه می‌تواند مناسب باشد؛ ولی روی متن‌های طولانی باید محدودش کنیم تا خوانایی حفظ شود.

If a user says “اکسترالیسم”, clarify the intended meaning instead of asserting that it is an established style. Offer maximalism or experimental design as possible interpretations, or ask for a reference.

## Image examples

If requested, use the available image-generation tool and read its skill instructions when required. Produce an actual visual using this project's name, language, realistic content, and intended device. For style comparisons, keep the content and viewport comparable. Show the result and identify it as a concept illustration. Do not claim exact implementation, accessible behavior, or measured fidelity from a generated image.

If generation is unavailable, explain the limitation and offer an HTML sample or genuine reference images. Do not pretend to have generated an image.

## Identity questions

Ask whether a visual identity already exists. If it does, invite the user to share the brand guide, logo, colors, typefaces, and image references through normal chat. If not, develop a basic identity that includes personality, palette, type, wordmark/logo direction, image/icon style, and voice. Do not assume that writing a logo description is the same as creating the logo asset.

## Remember the choices

Record the current topic, audience, style, font preference/delegation, color preference/delegation, identity status, theme, preview route, optional page analysis, and any approval. A follow-up question about fonts or styles does not reset the interview.
